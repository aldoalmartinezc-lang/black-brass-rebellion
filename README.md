# BLACK: Brass Rebellion

> *"Trabajé para el humo. Ahora disparo por la luz."* — Black

Juego de arcade tipo shoot 'em up ambientado en un universo steampunk espacial. Generado con el workflow Cowork + Claude + Codex CLI.

## Jugar

**En línea:** [Jugar en GitHub Pages](https://[USUARIO].github.io/black-brass-rebellion)

**Localmente:**
```bash
npm install
npm run dev
# Abre http://localhost:3000
```

## Controles

| Acción | Teclado | Móvil |
|--------|---------|-------|
| Mover  | ← →     | ◀ ▶  |
| Disparar | Space | FIRE  |
| Pausar | P       | —     |

## Desarrollo

```bash
npm run test           # Unit tests
npm run test:coverage  # Con reporte de cobertura
npm run test:e2e       # Tests E2E con Playwright
npm run lint           # ESLint
npm run build          # Build para producción
```
